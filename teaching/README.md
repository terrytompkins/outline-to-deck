# Teaching material

Material from the November 2026 outline-to-deck workshops, kept for classes and demos. It was built with **v1** of the tool, so some details differ from the current rules (v1 used per-style tag lists, bare Mermaid blocks and Reveal.js 5). Company names have been replaced with generic wording. The complete v1 repository is tagged `v1-workshop` in `outline-to-deck-workshop-20261109`.

| File | What it is |
|---|---|
| `workshop-intro.html` | The workshop's introduction deck |
| `outlook-to-todo/PROMPT-SCRIPT.md` | A step-by-step prompt script for a live session, from brief to deck |
| `outlook-to-todo/transcript-inbox-to-todo-deck.md` | The full chat transcript of that session |
| `outlook-to-todo/interim-core.html`, `inbox-to-todo-workshop.html` | The interim and final decks it produced |

The prompt script is still a good test of the proposal rules: run its outline through the current linter and see which layouts and tags v2 would propose.
